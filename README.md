# My AI Coach

An AI-powered English learning application built with Kotlin, Jetpack Compose and Firebase.

## Features

- AI English Coach
- Personalized Learning
- Speaking Practice
- Reading
- Writing
- Listening
- Daily Goals
- Gamification

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Firebase Authentication
- Firestore
- Room
- Gemini
- Docker
